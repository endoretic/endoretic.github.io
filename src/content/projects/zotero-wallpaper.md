Zotero Wallpaper sets a background image behind the Zotero 10 library
interface, using only local files.

Light and dark modes take separate wallpapers. A wallpaper can be a single
image or a folder, and a folder rotates in shuffled order without repeating
until the set is exhausted. Opacity is adjustable, and layout offers Cover,
Contain, Center, and Stretch, with size and position controls for the
single-image case.

It installs as an XPI from the repository releases, through `Tools → Plugins`,
and is configured under `Edit → Settings → Zotero Wallpaper`. The repository
notes that it may conflict with theme plugins.
